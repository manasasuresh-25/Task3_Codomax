# CodSoft Data Analytics Internship – Task 1

## Data Cleaning & Preprocessing

### Objective
The objective of this task is to clean and preprocess the raw Netflix dataset by handling missing values, removing unnecessary data, checking for duplicates, and preparing the dataset for further analysis.
## Dataset
 Netflix Movies and TV Shows Dataset
## Tools & Technologies
- Python
- Jupyter Notebook/VS Code
- Pandas
## Data Cleaning Steps Performed
- Imported the dataset into Jupyter Notebook/VS Code.
- Examined the dataset structure using `head()`, `info()`.
- Checked for missing (null) values.
- Verified duplicate records.
- Removed unnecessary columns (`show_id`, `rating`, and `date_added`).
- Filled or handled missing values in the remaining columns.
- Converted data types where required.
- Saved the cleaned dataset as a CSV file.
## Files Included
- `netflix_titles.csv` – Original dataset
- `cleaned_data.csv` – Cleaned dataset
- `task1_data_cleaning.ipynb` – Jupyter Notebook containing the preprocessing code
## Outcome
The dataset was successfully cleaned and prepared for Exploratory Data Analysis (EDA). Missing values were handled, unnecessary columns were removed, duplicate records were checked, and the cleaned dataset was exported as a CSV file.
